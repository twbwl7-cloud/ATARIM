# דוד טובול — אתר תדמית

אתר תדמית פרימיום בעברית (RTL). אוניקס + זהב שמפניה, עכבר מותאם, MacBook 3D, וכל סקריפטי הדימו/מילים/אנימציות — לא דף נחיתה.

## סטאק

Next.js · TypeScript · Tailwind · Framer Motion · Lenis · React Three Fiber

## הרצה

```bash
npm install
cp .env.example .env.local
npm run dev -- --port 43128 --hostname 127.0.0.1
```

פתחו [http://127.0.0.1:43128](http://127.0.0.1:43128)
