# דוד טובול — פורטפוליו פרימיום

אתר תיק עבודות בהיר בעברית (RTL). תכלת מהלוגו, זהב מתכתי, מחשב תלת־ממד ב־Hero, ודוגמה בחינם לפני תשלום.

## סטאק

Next.js · TypeScript · Tailwind · Framer Motion · Lenis · React Three Fiber

## הרצה

```bash
npm install
cp .env.example .env.local
npm run dev -- --port 43128 --hostname 127.0.0.1
```

פתחו [http://127.0.0.1:43128](http://127.0.0.1:43128)

## מבנה הבית

1. ילון כניסה עם הלוגו
2. Hero בהיר + MacBook תלת־ממד (צף, בלי גלילה מסונכרנת)
3. מרקי אמון
4. עבודות חיות במסגרות מכשיר (מוקטנות, בלי חפיפה למלל)
5. דוגמה בחינם
6. למה איתי (נוסחת H18 — מה שלא עושים)
7. תהליך בחמישה שלבים
8. יצירת קשר
9. עליי + דיוקן
10. המלצות
