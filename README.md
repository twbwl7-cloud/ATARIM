# דוד טובול — פורטפוליו (Daylight Atelier)

אתר תיק עבודות בהיר ויוקרתי בעברית (RTL). מטרה: להביא לקוחות — דוגמה בחינם, הוכחות חיות, גלילה נעוצה.

## מה מפעילים מה־doks

| מקור | מה נכנס |
|------|---------|
| ספר מיליוני אתרים | P01 רושם ראשון · P05 פער סקרנות · P07 סיפור גלילה · P14 הוכחה · A05 נעוץ · A10 מרקי |
| אנימציות | ילון כניסה · כפתור מגנטי · fade/stagger |
| סקריפט דימו | Lenis · signature moment · WOW scroll |
| דף נחיתה | AIDA · sticky WhatsApp · מיקרו־אמון · בלי מחסור מזויף |
| סקריפט 6 | קופי אנושי · בלי באזז AI · H1 קצר |

## סטאק

Next.js · Tailwind · Framer Motion · Lenis · Hebrew RTL

## מבנה הבית

1. ילון כניסה → Hero בהיר (המסך נשאר, האור והמילים זזים)
2. מרקי אמון
3. עבודות במסגרות מכשיר (מובייל↔מובייל, מחשב↔מחשב)
4. סיפור נעוץ — מה לא עבד
5. למה איתי · תהליך · דוגמה בחינם · המלצות · עליי · יצירת קשר
