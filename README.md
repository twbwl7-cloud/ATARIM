# דוד טובול — ארכיון פורטפוליו אינטראקטיבי

חוויית ארכיון תלת־ממדית (קובץ יחיד) לפיתוח חוויות דיגיטליות ופלטפורמות פרימיום.

## הרצה

```bash
python3 -m http.server 43128 --bind 127.0.0.1
```

פתחו [http://127.0.0.1:43128](http://127.0.0.1:43128).

## מה בפנים

- Splash → סרטון פתיחה (×2) עם דילוג
- כדור תמונות Fibonacci (21 כרטיסים) — פרויקטים, ביקורות והסיפור
- כותרת ממורכזת: «בונה חוויות שנראות כמו יוקרה»
- גרירה לסיבוב, גלילה קצרה לזום, רשת שטוחה, לייטבוקס FLIP, תפריט מלא
- עברית · CTA לוואטסאפ

עדכנו מספר וואטסאפ ב־`index.html` (חיפוש `972500000000`).

## Next.js (אופציונלי)

תיקיית `src/` מכילה גם גרסת Next קודמת. האתר הפעיל הוא `index.html`.
